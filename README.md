# NurIslam - Islamic Mobile Web App

Aplikasi web Al-Qur'an, Jadwal Shalat, Doa Harian, dan Hadis Shahih berbasis Web Mobile.

## 🚀 Fitur Utama
- **Al-Qur'an Digital**: 114 Surah lengkap audio & terjemahan (Sumber: [EQuran.id](https://equran.id)).
- **Jadwal Shalat**: Akurat berdasarkan lokasi kabupaten/kota di Indonesia.
- **Doa & Dzikir**: Kumpulan doa harian shahih.
- **Kutubut Tis'ah**: 9 Kitab Hadis Shahih.
- **Tasbih Digital**: Penghitung zikir interaktif.

## 🛠️ Teknologi
- HTML5, Tailwind CSS
- JavaScript (ES6 Modules)
- EQuran API (v2)
